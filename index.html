07
Incentive Design · Collections Strategy · FinTech
Agent Incentive Optimization: Weighted Rank Model Driving $6M
SQLPythonClaude Artifact In the lab
↓

The existing incentive structure rewarded total balance volume only — so agents chased easy accounts and ignored high-delinquency buckets. I redesigned the framework using a weighted rank model: Balance Moved (70%) + Buckets Cured (30%), with higher delinquency buckets (B4, B5) earning more points. Top 70% of agents eligible, with a 70/30 bonus split.

Redesign shifted agent focus to B3+ delinquency buckets — highest recovery opportunity
$6M incremental balances moved from segments that were previously deprioritized

How I Work

Analytics as a system, not a report.

Every project follows the same discipline — start with the business question, not the data.

◎

Business-First Framing

Every analysis starts with a stakeholder workshop — not a data pull. Question → Metric → Data. Measure what matters, not what's easiest to query.

⊕

Rigorous Root Cause

Metrics lie when context is missing. Validate pipelines, isolate variables, never present a finding I can't reconcile back to its source. Trust — then verify.

◈

Executive-Grade Output

Insights that don't change decisions are just reports. Designed for the 30-second scan — clear KPI hierarchy, one implication, one recommended action.
